# Зависимости

Для работы приложения должны быть доступны сервисы:
1. danshin_id API
2. danshin_notice API

## Тестирование

Для тестирования нужны работающие сервисы:
1. danshin_id API - java -jar app.jar --spring.profiles.active=dev
2. danshin_notice API - java -jar app.jar --spring.profiles.active=dev
